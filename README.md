# FPVSIM

Симулятор FPV-дрона від першої особи на Three.js. Злітаєш із трави, шукаєш ціль по квадратах,
виходиш на неї. Без стрілок-маркерів і без мінімапи в польоті: єдина навігація — компас,
брудне аналогове відео та те, що ти запам'ятав із брифінгу.

Дизайн-документ і правила проєкту — у [CLAUDE.md](CLAUDE.md).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 147 тестів
npm run build      # tsc --noEmit + vite build
```

`?level=2` в URL — стрибок одразу на потрібний виліт.

## Керування

| Дія | Клавіатура | Геймпад (mode 2) |
|---|---|---|
| Газ | `W` / `S` (накопичувальний) | лівий стік ↕ |
| Рискання | `A` / `D` | лівий стік ↔ |
| Тангаж | `↑` / `↓` | правий стік ↕ |
| Крен | `←` / `→` | правий стік ↔ |
| Арм / дизарм | `Space` | A |
| Рестарт | `R` | Start |

Дрон **не зависає сам** — газ тримає пілот. Бойові рівні йдуть в ACRO без автовирівнювання.

## Структура

```
src/
  flight/    ядро польоту — чистий TS, БЕЗ three.js, тому тестується в node
  drones/    характеристики дронів і навантажень — самі дані
  level/     рельєф із seed, сітка квадратів, специфікації рівнів
  game/      цілі, маршрути, правила місії, збірка вильоту
  render/    світ, FPV-камера із затримкою відео, аналоговий тракт, машини
  ui/        брифінг-мапа, OSD, дебриф
  core/      ввід, звук
tests/       147 тестів; playable.test.ts проходить обидва рівні автопілотом
```

Два правила, які тримають проєкт: **уся поведінка — в даних** (новий дрон або рівень
не потребує коду) і **`flight/` не знає про рендер** (тому фізику видно в тестах, а не на око).

## Що вже відчувається по-різному

Виміряно, а не заявлено — цифри збігаються з `tests/payload.test.ts`:

| Дрон | TWR (без БК) | Темп крену через 50 мс повного стіка |
|---|---|---|
| 7" тренувальний | 4.1 | 316 °/с |
| 7" легкий | 3.5 | 203 °/с |
| 8" середній | 2.8 | 83 °/с |
| 10" важкий | 2.6 | 35 °/с |

Навантаження додає до цього три ефекти: ріже запас тяги, сповільнює обертання
(крен/тангаж — так, рискання — ні) і опускає центр мас, через що дрон гойдається
маятником після кожного різкого стіка.

## Діагностика

```bash
PROBE=1 npx vitest run tests/probe.test.ts   # відгук, TWR, максималка, маятник
```

У режимі `dev` глобальна змінна `window.fpv` дає доступ до `session`, `world`, `camera`.
