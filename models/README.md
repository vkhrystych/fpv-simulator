# Game models

Галерея фактичних моделей гри: сторінка імпортує `buildVehicle()` і білдери
пропсів прямо з `src/render/`, тому показує рівно те, що рендериться в польоті,
і розійтись із грою не може. Працює тільки під dev-сервером (імпортує TS).

Панелі техніки — види, які кампанія реально використовує (зібрані з
`src/level/levels.ts`): target / civilian / decoy, плюс «Camo net», якщо клас
десь стоїть під сіткою. Панелі пропсів — варіанти, між якими світ обирає
хешем координат.

## Запуск

```bash
npm run dev
# відкрити http://localhost:5173/models/
```

## Керування

| Клавіша | Дія |
|---|---|
| `←` `→` | попередній / наступний об'єкт |
| миша | тягнути — обертати, колесо — зум |
| `f` | ракурс: орбіта ↔ бойовий (60 м, кут ~15°) |
| пробіл | автообертання |
| `r` | скинути камеру |

## Файли

| Файл | Що всередині |
|---|---|
| `catalog.js` | збирає каталог з ігрового коду: техніка × використані види, пропси × варіанти |
| `viewer.js` | сцена, світло, камера панелі |
| `app.js` | список, панелі, камера |

## Історія

Спочатку це був **пікер**: 45 рукописних варіантів (по 3 стилі на об'єкт),
відмітки → `models-config.json` → перенесення в гру. Той цикл завершено:
конфіг від 05.08.2026 застосовано, а з 06.08.2026 техніка — запечені GLB
(`assets/mil/`, `scripts/bake-vehicles.mjs`). Рукописні варіанти й `check.mjs`
видалено разом із режимом вибору; історія — у git.

Звідти ж лишаються правила для будь-якої нової моделі:

1. Вісь **Z — угору**, об'єкт стоїть на `z = 0`.
2. Ніс машини дивиться в **+Y** — `VehicleRenderer` крутить групу навколо Z.
3. Габарити беруться з каталогу: силует — це складність, танк мусить лишитись 9.5 м.
4. Модель вписана у свій колайдер (`tests/render.test.ts`).
